# Чёрный паук

Браузерная игра про чёрного паука. Нажимаешь на паука и на всё вокруг, он отвечает голосом и проходит этапы. В главном меню два эпизода:

- **Эпизод 1. Знакомство** (10 этапов): разбудить паука, сделать разминку, поймать букашек, обогнать фиолетового, красного и синего пауков, не есть невкусных ос и зелёных вонючек, успеть съесть синих ядовитых и не попасться зелёному пауку-щекотуну.
- **Эпизод 2. Чёрный паук идёт спать** (8 этапов): туалет, зубы, душ, найти спальню, говорящее одеяло, книжка со сказкой, обнять маму и папу, выключить свет.

Пройденный этап запоминается в браузере (`localStorage`), так что игру можно продолжить с того же места.

## Как устроен репозиторий

- `src/game.html` — исходник игры (разметка, стили и код в одном файле, без обёртки `<html>`). В таком виде страница публикуется в чате Claude.
- `build.py` — собирает из него `index.html` для GitHub Pages: `python3 build.py`.
- `index.html` — собранная страница, её и отдаёт Pages.
- `.nojekyll` — пустой файл, чтобы Pages отдавал файлы как есть.

Оба эпизода и меню живут в одной странице. Картинок и звуковых файлов в репозитории нет: вся графика нарисована прямо в коде (SVG и CSS), поэтому, кроме шрифтов, игра ничего не подгружает.

Правится только `src/game.html`, после правки нужно запустить `build.py` и закоммитить оба файла.

## Запуск у себя

```
python3 build.py
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Звуки, голос и шрифты

- **Голос** не записан и не сгенерирован заранее. Фразы произносит синтезатор речи самого устройства (Web Speech API, `speechSynthesis`) русским голосом, с разной высотой для разных персонажей. Поэтому на разных телефонах и компьютерах голос звучит по-разному, а если русского голоса на устройстве нет, остаются только облачка с текстом.
- **Звуковые эффекты** (прыжок, хруст, фанфары, колыбельная и остальные) синтезируются в браузере через Web Audio API, без аудиофайлов.
- **Шрифты** Rubik Mono One и Nunito подключаются с Google Fonts. Без сети страница работает с запасными системными шрифтами.
